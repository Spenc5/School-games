# School Games

Click-to-play games for running sessions over Zoom (share the browser window
and give Remote Control to whoever's turn it is). Everything is plain
HTML/CSS/JavaScript — no install, no build step, works offline once loaded.

Open `index.html` for a menu of all the games.

| Folder | Game |
|---|---|
| `chess/` | ♟ Chess — click-to-move, legal-move hints, optional computer opponent |
| `sugar-summit/` | 🍭 Sugar Summit — candy board game with a spinner, ladders and slides |
| `silly-critters/` | 🐛 Silly Critters — spin-and-build critter game for ages 5–6 |
| `life-paths/` | 🛤️ Life Paths — Life-style board game with social situations and coping skills |
| `matching-game/` | 🎴 Matching Game — two-player memory matching |

Each folder has its own README with details. These games were moved here from
the `stemplicity` repository, which now holds only the math activities.
