# Matching Game

A two-player memory-matching (concentration) game: flip two cards at a
time looking for a pair. Find a match and you score a point and go
again; miss, and the cards flip back and it becomes the other player's
turn. The player with the most pairs when the board clears wins.

- Turn-based, two-player scoring with a live score/turn banner
- Three difficulty levels (12/16/24 cards)
- Card-flip animation, keyboard accessible (Tab + Enter/Space)
- No dependencies — pure HTML/CSS/JS

Files: `index.html`, `style.css`, `app.js` in this folder.
